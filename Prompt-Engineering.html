Writing Optimized Prompts

💡 What Makes a Prompt Effective?

An effective prompt eliminates ambiguity and guides an LLM to generate the exact expected output on the first attempt. Think of an LLM as a brilliant intern with amnesia: without explicit domain context, guardrails, and target formatting, it will produce generic or off-target results.

🧩 The 7 Key Components of a Good Prompt

Universal formula: [ROLE] + [CONTEXT] + [TASK] + [REQUIREMENTS] + [CONSTRAINTS] + [EXAMPLES] + [OUTPUT FORMAT]

1. Role

Assign a Persona

Sets the mindset, domain knowledge level, and vocabulary tone.

2. Context

Background Info

Explains the situation, target audience, and business objective.

3. Task

Primary Action

Specific command beginning with a strong verb (e.g. Write, Refactor).

4. Requirements

Must-Have Features

Functional criteria and standards that must be satisfied.

5. Constraints

Guardrails & Limits

Explicit rules detailing what NOT to do or library restrictions.

6. Examples

Few-Shot Samples

Sample input/output pairs that demonstrate desired behavior.

7. Output Format

Structure Rules

Raw JSON schemas, Markdown blocks, or bullet lists.

💡 Prompt Engineering Tips

Here are some practical tips to keep in mind when working with LLMs:

  • Ask negative Questions: Frame questions to explore boundaries or what the model should avoid doing.
  • Old LLMs are trained with Old Information: Be aware that models have knowledge cutoffs and might lack recent context.
  • Check LLM result with other LLM: Cross-verify outputs across different models to ensure accuracy and reduce hallucinations.
  • Plan before coding: Create flowcharts, sequence diagrams, and test cases first, then start the development work.
    • Example: Do not begin coding until the flowchart and sequence diagram match your expectations to complete the task.

Prompt Engineering

🧠 Definition & Core Concepts

Prompt Engineering is the engineering discipline of designing, optimizing, and programmatically managing input context windows and LLM configurations to produce predictable, structured, and hallucination-free outputs without retraining model parameters.

🛠️ Core Techniques (With Practical Examples)

1. Zero-Shot Prompting

Direct instructions given without prior examples. Best for standard tasks.

Classify sentiment: "The shipping was delayed, but the item quality is outstanding!"

2. Few-Shot Prompting

Providing 1 to 5 input-output demonstrations to anchor pattern recognition.

Input: "Great service!" -> Sentiment: Positive
Input: "Broke immediately." -> Sentiment: Negative
Input: "Package was intact." -> Sentiment:

3. Structured Output (JSON / Schema)

Forcing the LLM to return strict JSON for API consumption.

Extract entities into raw JSON matching: {"name": string, "role": string, "budget": number}.
Text: "Sarah Jenkins, Head of DevOps, approved a $15,000 budget."

4. Context Provision & Grounding (RAG)

Injecting external reference documents into the prompt window to eliminate hallucinations.

Answer strictly using the provided context.
Context: [Section 4.1: Subscriptions can be canceled within 14 days for a full refund.]
Question: What is the refund period?

Loop Engineering

🔄 Definition & Agentic Architecture

Loop Engineering is the practice of wrapping an LLM inside an autonomous, closed-loop state machine. Instead of relying on a single text answer, a loop-engineered AI agent executes tool actions, observes environment logs, evaluates results, and self-corrects until its goal is verified.

Comparison Matrix

Focus Text formatting, role, context, & constraints. Input/output schemas, RAG, few-shot techniques. State loops, tool execution, feedback, retries.
Scope Single prompt turn. Application context pipelines. Multi-step agentic execution.

Final Revision & Quiz

🎓 2–3 Line Interview Definitions

Writing Optimized Prompts:

The practice of crafting structured natural language instructions incorporating role, context, task, constraints, and output format to get precise single-shot outputs from an LLM.

Prompt Engineering:

The technical discipline of programmatically managing context windows, retrieval systems (RAG), and output schemas to ensure reliable, structured LLM behavior across software applications.

Loop Engineering:

The architecture of closed-loop AI agent systems where an LLM executes tool actions, receives runtime environmental feedback, evaluates progress, and self-corrects until a goal is satisfied.
