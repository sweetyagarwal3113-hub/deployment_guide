What is a SKILL.md File?

A comprehensive developer guide detailing the structure, purpose, execution checklists, and repository architecture of SKILL.md files for AI coding agents.

💡 What is a SKILL.md file?

A SKILL.md is a Markdown instruction file used by AI coding agents and agentic frameworks to define a specific skill or capability.

It contains instructions that tell an AI agent how to perform a particular type of task—including the steps it should follow, rules it should respect, tools it may use, and the expected output format.

📌 In Simple Words:

SKILL.md is like a training / instruction manual for an AI agent for one specific task.

Project Skills Directory Hierarchy Example:

DIRECTORY STRUCTURE 
skills/
├── code-review/
│   └── SKILL.md
├── testing/
│   └── SKILL.md
├── documentation/
│   └── SKILL.md
└── deployment/
    └── SKILL.md

Each SKILL.md file describes one specialized, reusable skill.

🎯 Why is SKILL.md used?

Without specific instructions, an AI agent may perform the same task differently each time.

For example, suppose you simply ask: "Review this code."

A SKILL.md file for code review provides a defined process for the agent:

❌ Without SKILL.md

  • Inconsistent output format
  • Random focus (sometimes ignores security)
  • May alter code without request

✅ With SKILL.md Checklist

  1. Check for bugs.
  2. Check security issues.
  3. Check performance.
  4. Check code quality.
  5. Check error handling.
  6. Give suggestions.
  7. Do not modify the code unless requested.

🧩 What Can a SKILL.md File Contain?

A typical skill file contains 5 core structured sections:

1. Skill Name (# Code Review Skill) — Identifies the skill.
2. Description — Explains what the skill does and when to use it.
3. Instructions (## Instructions) — Step-by-step workflow the AI must follow.
4. Rules & Constraints (## Rules) — Defines boundaries and limits.
5. Expected Output Format (## Output Format) — Directs how to present results (e.g. Bugs, Security, Suggestions).

📝 Real-World Example

Suppose you have a Node.js project. You create skills/api-development/SKILL.md:

skills/api-development/SKILL.md 
# API Development Skill

## Purpose
This skill explains how to create REST APIs in this project.

## Process
1. Create the route.
2. Validate request data.
3. Create the controller.
4. Put business logic in the service layer.
5. Handle errors.
6. Add authentication where required.
7. Write tests.
8. Update API documentation.

## Rules
- Use async/await.
- Do not put business logic directly in routes.
- Validate user input.
- Never expose passwords or API keys.
- Follow the existing project structure.

When the AI is performing API development, this skill provides exact instructions for that particular task.

⚔️ SKILL.md vs AGENTS.md

This is the most important architectural distinction:

AGENTS.md

Project-Wide Instructions

"How should the AI work in this project?"

  • General project rules & repo context
  • Applies everywhere in the codebase

SKILL.md

Specific Task Instructions

"How should the AI perform this particular task?"

  • Focused instructions for one skill
  • Activated on-demand per task type
PROJECT REPOSITORY STRUCTURE 
Project
│
├── AGENTS.md          ──► General project rules
│
└── skills/
    ├── testing/
    │   └── SKILL.md   ──► Instructions for testing
    ├── code-review/
    │   └── SKILL.md   ──► Instructions for code review
    └── deployment/
        └── SKILL.md   ──► Instructions for deployment
Memory Formula:

AGENTS.md = Rules for working on the project

SKILL.md = Instructions for performing a specific skill

❓ Is SKILL.md a Programming or Linting File?

No. SKILL.md is a Markdown instruction/documentation file. Its special meaning comes from the AI tool or framework that recognizes and loads it.

It is different from files such as:

File Name Category Primary Role
eslint.config.js Linting Rules Automatically checks JavaScript/TypeScript code format & errors
tsconfig.json TypeScript Config Configures compiler rules and type checking
package.json Package Manifest Manages project dependencies, scripts, and metadata
.env Environment Config Stores secret runtime environment variables
SKILL.md AI Skill Instructions Defines workflow & rules for an AI agent performing a task
AGENTS.md AI Agent/Project Guide Defines overall project rules for AI collaboration
Key Insight: SKILL.md vs. Linter

An ESLint rule automatically checks and flags code compliance in your editor or build tool.

A SKILL.md file tells the AI: "Use async/await."

Therefore, SKILL.md guides the AI; it does not itself enforce code like a linter or compiler.

📌 One-Line Definition for Your HTML / Documentation:

"SKILL.md is a Markdown-based instruction file that defines how an AI coding agent should perform a specific task or skill, including its workflow, rules, constraints, tools, and expected output."

Note: SKILL.md is not a universal standard built into all AI tools. The exact way it is discovered and used depends on the AI coding agent or framework.
