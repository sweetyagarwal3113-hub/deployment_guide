Complete Web Application Deployment Guide

Step-by-step instructions for deploying a Next.js / Node.js Backend & Static Frontend on mPanel server architecture.

Node Version 20.20.2 (or latest)
App Mode Automatic
Proxy Enabled ON BLUE
Port / Path 3000 / /
1
My Website Setup & Domain Addition

Begin by registering your domain into the mPanel management console:

  • Navigate to My Website section from the main navigation dashboard.
  • Click on Add Website button.
  • Write your target domain name in the input field (e.g., example.com or subdomain.example.com).
💡
Tip: Ensure your domain's DNS A-record is properly pointed to your mPanel server IP address before proceeding.
2
Node.js Application Configuration

Configure the Node.js runtime environment parameters in mPanel as follows:

Setting Parameter Required Configuration / Value
Application Mode Automatic (Production)
Node Version 20.20.2 (or latest recommended LTS version)
Startup Command npm start
Working Directory backend
Proxy Enabled ON (Ensure the Blue Toggle switch is active)
Path / (Leave BLANK)
Port 3000
3
Frontend Deployment (public_html)

Build and publish compiled static assets to the standard web root:

  • Run command in your local frontend project directory: npm run build
  • Zip the output compiled contents (zip the contents inside the dist/ folder, NOT the dist directory itself).
  • Upload the zipped bundle and extract all files/folders inside the public_html directory.
📂 public_html Directory Structure (Extracted Contents of dist):
📁 public_html/
📄 index.html (main compiled entry point)
📁 assets/ (compiled CSS, JS, fonts & static media)
📄 ... (all other compiled dist files & images)
⚠️
Important Zipping Rule: Select and zip the files/folders inside the dist/ directory (e.g., index.html, assets/, etc.) rather than zipping the parent dist folder itself. This ensures index.html lands directly in the root of public_html/ upon extraction.
4
Backend Deployment (backend folder)

Set up the backend Node.js application directory:

  • Create a folder named backend directly in the root directory (outside of public_html).
  • In your local backend codebase, execute: npm run build
  • Compress (zip) and upload all essential server files and dependencies into the backend/ folder.
📁 backend/ Directory Content Checklist:
📁 backend/
📁 node_modules/ (REQUIRED: production dependencies for npm start)
📁 .next/ (REQUIRED: compiled Next.js build output)
📁 public/ (INCLUDE IF USED: static images, favicon, media files)
📄 server.js (REQUIRED: main server entrypoint)
📄 package.json (REQUIRED: manifest with "npm start" script)
📄 .env (REQUIRED: environment configuration variables)
❌ src/ (NOT NEEDED: source code is compiled inside .next/)
💡
What to Include vs Exclude:
  • Include node_modules/: Yes, required so the Node.js server can load dependencies on startup.
  • Include public/: Yes (if used). Required if your backend serves static assets, images, icons, or uploaded media files directly.
  • Exclude src/: No need to upload src/ folder. All React/TypeScript code is already compiled into .next/. Excluding src/ saves space and protects your raw source code.
⚠️
Environment Variables & Hidden Files: mPanel does not feature a separate Environment Variables UI section in the control panel. You must upload your .env file directly inside the backend/ folder. Also ensure hidden folders (like .next/) and dotfiles (like .env) are explicitly included in your zip archive before uploading.
5
Server Restart & Final Verification
  • Return to the Node.js tab inside your mPanel control panel.
  • Click the Restart Server button to apply changes and spawn the application instance.
  • Visit your domain URL in the browser to verify site functionality.
🎉
Verification Complete: If configured correctly, your proxy routes requests smoothly between the public frontend assets and the backend Node.js service running on port 3000.
